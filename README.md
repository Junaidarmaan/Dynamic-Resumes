# dev-template

## Contribution Guidelines

We warmly welcome contributions from everyone. To maintain the project's quality and consistency, we ask that you follow these simple guidelines:

- **Modular Design**: Ensure that the code you contribute is modular and well-separated in terms of responsibility. Avoid tightly coupled components.
- **Clarity and Documentation**: Whenever possible, provide comments and documentation for understanding your code.
- **Coding Standards**: Adhere to the existing coding standards and formats used throughout the project.
- **Testing**: If applicable, add or update tests to ensure the reliability of your contributions.

Thank you for helping us make this project even better!
